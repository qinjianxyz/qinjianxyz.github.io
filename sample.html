02 / BUILD

改成你想做的题目。Make it your own.

先发布一条虚构信息，搜索，再刷新。然后在 PROJECT.md 写下服务谁；修改 index.html 中的项目名称和一个输入提示，保存后再试。Publish a fictional listing, search, and refresh. Describe your audience in PROJECT.md. Change the project name and one input hint in index.html, save, and try again.

可以用 AI 解释代码。做完后，自己指出改了哪里、为什么改，以及页面发生了什么变化。Use AI to help explain the code. Afterwards, point to your changes and explain why you made them and what changed on the page.

03 / CHECK

自己检查，不只看截图。Check what actually works.

  • 项目名称与提示已改变，发布和搜索仍能用。Your name and hint changed; publishing and searching still work.
  • 刷新页面、重启服务后，信息仍在。The listing survives a refresh and a server restart.
  • 搜索不存在的词时，有明确提示。A search with no match gives a clear message.
  • 你能说明页面、服务器和数据库各做了什么。You can explain what the page, server and database each do.
已经写过代码？试试搜索里的空格问题。Already coding? Try the search challenge.
